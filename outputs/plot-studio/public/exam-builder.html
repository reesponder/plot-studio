What the exam covers

Build an editable project for Northline Tool Library. Visitors compare loan options, calculate a quote and send a well-formed enquiry.

24 tasks in four modules

You get six hours of active work. The full brief opens when you start. The server grades your submitted project. You need 80 out of 100 and all required checks.

  • Build the public site

    Six tasks on page structure, accessible content, navigation and responsive layout.

  • Build the interactive quote

    Six tasks on browser events, typed values, calculations and responses to invalid input.

  • Connect and protect enquiries

    Six tasks on the enquiry form, data access and useful feedback for customers and staff.

  • Test and hand off the project

    Six tasks on checking the visitor journey, data and the editable project you submit.

How to prepare

Work through the foundations, then rehearse the same skills in a fresh project before your timed session.

Foundational practice

These two worked drills use the earlier Studio Enquiry scenario.

  • Create the three pages

    Set up the pages and test the route from the home page action.

  • Wire the live result

    Watch the Contact text change after a valid submission.

Rehearse from a blank draft

  1. Lay out two pages

    Build Screen Printing and Workshop Info. Link them in both directions and stack the class listings in Phone Preview.

  2. Add a small interaction

    Build an estimate from a class selector and a quantity field. Connect the calculation to a visible result with Blueprint.

  3. Test before and after export

    Try a valid quantity, a fraction and a blank field. Reopen the editable file in a separate draft and check the same paths.

Ready for the exam?

  • I can follow the site’s own links at desktop and phone widths.
  • I can identify the execution wire and the wire that carries a value.
  • I can explain what changes on valid input and what stays put on rejected input.

Submission and scoring

Upload one editable .plot file per submission. The exam workspace shows the result and the checks to review before trying again.

What the grader inspects

The grader checks your site and the behaviour of the quote and enquiry workflows. Save the file via Download .plot project and test the exact file you will submit.

How to use your submissions

You can submit up to three versions while the session is active. When a check fails, use the exam workspace to identify it. Reproduce the issue in Preview before trying another upload.

How the certificate works

After passing, issue the certificate and download its PDF in the exam workspace. Enable public verification before sharing the reference ID or verification link.

For hiring teams

Builder is relevant to roles that own site pages, responsive layouts and browser interactions. Ask candidates to explain a breakpoint choice or follow an interaction from its page block to its Blueprint result. Verify a certificate.
