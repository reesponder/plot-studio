Compose the page around a decision

Write the main question the visitor brings to the page and the action they should be able to take. On an architecture portfolio, that might be whether the studio has handled a similar renovation. A relevant project, a short description of the scope, and a way to ask about availability can answer it.

Sketch the order in plain text. Lead with the project or offer, place its evidence nearby, and add supporting information where the visitor will need it. Give each region a purpose. If readers compare options, use repeated structure. If they follow a sequence, let each step have the room its content needs.

Build the hierarchy in Layers

Open Design and choose blocks in Elements. Start with a Section for each region and add the actual headings, text, and actions. Nest related blocks inside the same container and use Layers to inspect the resulting order. Add Columns only where adjacent content benefits from being compared or read together.

Use the block’s Content tab for words, links, sources and element-level options. Use Style for its layout and appearance. Read the page from top to bottom before polishing local details. That order carries into the narrow layout and influences keyboard navigation.

Choose an editable block variant

In Design, open Elements → Variants to browse the library, or click the style count beneath a specific element. Search for a block, then compare its layouts and four color palettes in the Desktop and Phone previews. The normal element button still adds the default block; you can also drag that button onto the canvas.

For a page with many destinations, open Navigation and compare a layout that gives links room with one that puts secondary pages in a menu. A hero variant controls the introduction below that navigation. Try one with the real page title before committing to a large or unusually narrow heading.

Select an existing block and choose Change variant from the inspector to try another appearance in place. Then use Content to edit the words, links and images and Style to adjust the result. Use the device controls to check the result at each width.

Move and resize on the canvas

With Canvas transform enabled, select a block in Design. Pull the Move element grip to reposition it, or drag an edge or corner to resize it. Hold Shift to constrain movement to one axis or keep the proportions when resizing from a corner. With a handle in focus, the arrow keys adjust it by one pixel, or ten with Shift. Esc cancels a drag, and Undo reverses a completed gesture.

For an exact offset, open Style → Position and enter Canvas X and Canvas Y. Moving a block leaves its space in the layout intact. Reorder or nest it in Layers to change the structure itself, or use the inspector’s positioning controls for deliberate overlaps. Switch the canvas to Tablet or Phone to adjust that breakpoint and see how the surrounding content fits.

Set type for the real copy

In Design, clear the block selection to see Site typography. Choose Body text and Headings, and set the site sizes for H1, H2, H3 and Paragraph. Search the font picker and compare its samples using the actual words you intend to publish. Check weight, punctuation, accents and long names.

Choose a clear hierarchy. Use one H1 for the page’s main subject. Use H2 for sections and H3 for their subsections. The Level in a Heading block sets its semantic role. You can change the visual size independently under Style and Typography.

A starting scale for a service page

Try 64 px for the desktop headline, 36 px for sections, 24 px for subsections and 17 px for body text. Use a body line height near 1.55 and start with a text maximum width of 62ch. Check the longest paragraph and most awkward headline before applying the scale widely. A regular display weight can be enough when the headline is already large.

Open Font family, Size, Weight, Line height, Letter spacing and Alignment in the block inspector when that block needs a deliberate exception. Enter 1.55 as a unitless line-height ratio and lengths such as 42px for size. A Hero has a dedicated Hero title size setting. Give the phone headline a smaller local size if it buries the next action.

For a smoothly resizing title, try clamp(38px, 7vw, 96px) under Hero title size. At 390 px the minimum protects readability. On a wide screen the maximum prevents the headline from overwhelming the photograph. Change the middle value if you want the title to grow faster between those limits. See the site type scale and the local Hero setting.

Give colours specific roles

In the project menu, open Site themes. Editorial, Studio, Warm paper, Utility, Field notes and Technical each set a site-wide combination of display and body fonts, a type scale, background, text and accent. Choose the baseline early, then refine the blocks that need exceptions. Applying a theme later changes the shared settings, so revisit pages that already rely on them.

With the canvas deselected, use Site colors to change the accent. It appears in details such as primary buttons and focus outlines. For a specific Section, Heading or other block, use the Colors group in Style to set its background, text colour or opacity. Keep a short palette and assign roles you can reuse.

A solid background behind copy gives more predictable results. Identify success and errors in words. A message should still make sense when its colour cannot be distinguished. Place space where it belongs

Padding surrounds the contents inside a block. Margin is space outside the block. Gap defines the intervals between the children of a flex or grid container. If three cards need the same separation, set the container’s Gap rather than giving every card its own margin.

A practical starting rhythm is 8 px between a label and value, 16 px between related elements, 24 px between a paragraph and its action, and 56–80 px between sections. Set a single larger padding value on a Section as a starting point, then use the individual controls when top, right, bottom or left need different values.

Let content determine height

Use Style and Dimensions to set Width, Max width and Min height. A width of 100% follows the available container. A max width keeps a prose column or form from becoming unwieldy. A modest min height can give a hero or card breathing room while allowing longer content to grow.

When an element overflows, start with a long word, an unbroken URL, a fixed width, or the gap between columns. Try a general width or a narrower max width and check the children first. Use Overflow when a region deliberately scrolls or an image deliberately clips. Check keyboard focus and required text before clipping anything.

Choose a grid around the content

Add a Columns block and choose two, three or four columns in Content. Place the items inside it in Layers. Two columns can pair an image with an explanation. A group of three equal columns works for comparable items with similar amounts of information. Use a simpler grid when one item needs more space than the others.

For a specific proportion, select the Columns block and enter a value in Style, Layout, Grid columns. Try minmax(0, 3fr) minmax(0, 2fr) for a 60/40 split. Keep Gap around 24px while comparing the widths. The minmax(0, …) tracks allow columns to shrink when space is tight.

A Section can also become a layout container through Display. With Flex selected, configure Direction, Wrap, Main axis and Cross axis. Use a wrapping row for controls of unequal width. Use Grid when alignment across columns matters.

Test the grid with the longest title or widest image in the actual content. Read the column order with a keyboard, then switch to Phone to see where everything lands. For a layout override, set the phone grid explicitly to minmax(0, 1fr) where necessary.

Follow the same project from three tracks on Desktop to two on Tablet and one on Phone. In each view, the inspector shows which value belongs to that device.

Choose the hero’s proportions

Add a Hero block for the page’s opening. Set its heading, description, button label and URL. Choose Split for copy next to an image, Reverse for the opposite desktop arrangement, or Center for an opening with the copy centred above the image. If a Hero supplies the page’s H1, begin the next section at H2.

Use the image when it explains the work, shows the object or establishes a useful context. A close photograph can hold a compact crop. A product screen may need room for its text to remain readable. For a custom proportion, build a Section containing Columns and use separate Heading, Text, Button and Image blocks.

Test the first screen

Switch to Phone. Read the entire headline, see where the subject of the image lands and check how far the first action sits below the header. Shorten the copy, reduce the dedicated Hero title size or adjust section padding as needed. The built-in Split and Reverse layouts stack on narrow screens. Check their actual result in Preview.

Decide what changes at each width

Desktop is the base style. Tablet overrides apply through 1023px and Phone overrides through 767px. A Phone value takes precedence for its own property. Where no Phone value is set, the Tablet or Desktop setting applies. The Studio artboards use 820px for Tablet and 390px for Phone to represent common widths.

  1. In Desktop, set the order of blocks and a sensible base layout.
  2. In Tablet, check how many items can stay side by side. A four-column grid may need two tracks.
  3. In Phone, select specific blocks and set the local styles that need to differ, such as grid columns, type, gap and padding.
  4. Open Preview, choose each device and exercise the navigation, buttons and fields. Test a narrow real browser after exporting or publishing a rehearsal.

If a small-screen decision makes a larger problem, find the block in Layers and inspect the value that is being inherited. Clear overrides resets the selected block’s style for the selected device. Use it after checking whether you still need any other overrides on that same block.

Give phone users the same information and destinations they need to finish the task. Condense spacing and rearrange the reading order first. Keep the contact path and important feedback visible after the page stacks.

Use direct image URLs and deliberate crops

Add an Image, Hero, Card or Gallery. In Content, paste a direct https:// link or use Choose from assets. To prepare your own graphic or upload an image to Studio, follow the workflow in Paint and Assets.

For a Gallery, use one line per image in the form URL | Alt text | Caption. The alt text describes the information or function that matters in context. The caption can name the subject, credit the work or give detail readers need. Where an image is purely decorative and the same information is already present in the page, leave its alt text empty.

Set a frame and choose how it fills

Start with the source crop, especially for a hero image. A horizontal subject may be lost if a tall phone frame crops the sides. In Style, use Dimensions to test width, height, Aspect ratio and Image fit. Give the image a bounded frame when you need a specific ratio. Choose Cover when it may crop to fill and Contain when the entire image must be visible.

Compare a photograph and a chart in a 16 / 9 frame. Let the photograph fill the frame with Cover if the edges can be cropped. Use Contain for the chart so the axis labels survive. A row can share one aspect ratio while individual images use different fit settings. See the frame in the Dimensions inspector.

Use a screenshot at a size readers can inspect. Keep labels as real HTML when readers need to search, copy or enlarge them. For a broad graphic, include a useful description and a direct link to its full-size image if fine detail matters. Review long galleries on a mobile connection and use appropriately sized source files.

Find a photo in The Stock of Freedom

Open Assets → The Stock of Freedom and search by subject or setting. Use the category and orientation filters to narrow the results. Select an image for a larger preview, then choose Use on page for a quick insertion or Place on canvas to choose where it goes. Hold Shift when placing inside a container.

To replace an image in a Hero, Card or another existing block, start from Choose from assets on its image field. Studio stores a copy in Assets. Check the crop at the size you will publish and edit the alternative text for this page. See the catalogue’s license for its business-use terms.

Draw and place a graphic

For an icon, stamp or illustration that will sit on several backgrounds, start with a transparent sheet in Paint. Choose the height and width for the raster artwork, then choose the visible size separately in the page’s Dimensions. A small graphic should still read at its actual page size. Check the silhouette and any thin strokes in Phone Preview.

Build a badge with a clean edge

  1. In Paint, choose Add sheet. Name it, enter a square size such as 256 × 256 px and set Background to Transparent.
  2. Use Ellipse with Fill shape to draw the badge. Choose a colour that will read against the page. Use Brush or Line for the mark, then check its Stroke width and Opacity in Tool settings.
  3. Use Duplicate sheet from Sheet actions to make a light or dark variant. Name each sheet for the intended placement. Each one has its own canvas, and Paint can hold up to 24 sheets.
  4. Use Select to mark the bounds, then Crop selection to trim excess transparent space. Keep enough space around the graphic to fit its intended frame. Use Fit to see the whole sheet again.

Resize the image or adjust its canvas

Open Image and choose Resize. Scale image to fit resamples the artwork. Change canvas only sets its boundaries while the artwork keeps the same pixel size. Leave Keep aspect ratio selected when resizing a photograph or an illustration whose proportions matter.

For pixel art, choose Scale using nearest neighbor and use a whole-number factor such as 32 × 32 to 128 × 128. Zoom in and switch on Pixel grid to inspect the edges. The zoom and grid change your view while the dimensions set the exported size.

Prepare a transparent cutout

Open an image in Paint, or select an uploaded image in Assets and choose Edit in Paint. The image opens in a new sheet. For solid backgrounds and simple gradients, use Image → Remove background. Paint samples the corners and clears matching pixels connected to the outer edge.

Start with the default tolerance and inspect the checkerboard around the subject. Increase tolerance if a band of background remains. Undo and lower it if the subject loses detail. Leave Include matching pixels inside the drawing cleared when the subject has areas that share the background colour, such as white lettering on a white backdrop. For a complex edge, use the eraser at a closer zoom.

In Export, choose PNG or WebP to keep transparency. Choose JPEG with a background colour for a flat, opaque image. For a set of variations, All sheets · PNG ZIP downloads one PNG per sheet.

Place the finished image on a page

  1. Choose Save asset in Paint, then use Copy link in Asset link to share the public image URL. For a local image, open Assets and choose Upload images. It accepts .png, .jpg, .jpeg and .webp files up to 12 MB each.
  2. Choose Use on page to insert an Image block on the current page. To put the image in an existing block, select the block in Design, open Content, choose Choose from assets and then Apply to field.
  3. Set the image’s role using the block’s Alt text field. Put a badge’s actual message in page text when visitors need to read it to understand the page. Check the asset against the page background in Desktop and Phone Preview.

When Upload changes automatically is enabled, Paint uploads after you pause editing. A new saved version gets its own URL. Apply that version in Design when you want the page to display it. Asset URLs open for anyone with the link, including when the project itself is private.

Use borders and shadows to explain structure

Open Style and Border and shadow. Set a border’s Width, Style and Color as a group. Start with a solid 1px border for an input, a lightweight comparison surface or a selected item. Use Corner radius consistently across related components.

Use a shadow on a surface that needs depth or separation. In Shadow, try 0 8px 24px #0003 and compare it against the actual background. The values define horizontal offset, vertical offset, blur and colour. Review how a shadow looks at the edges of the phone artboard and inside any container that clips overflow.

Keep focus and selection distinct. Check links, form fields and buttons with Tab. A neutral border can identify a field, while a visible focus outline tells the keyboard user where the next action will occur.

Finish the paths people actually use

Navigation and page anchors

Use Navigation to set a brand name and the destinations that belong in the header. Add pages automatically is convenient for a short site. For a larger site, switch it off and enter one Label | URL pair per line. Prioritise the destinations people will need regularly. Test the mobile menu, its labels and the way back to Home.

Give a Section or Heading an Anchor ID such as pricing and link to #pricing from the same page. Use the editor’s internal page destination for another project page. Check both links in Preview after editing page slugs. Name buttons for the action they perform, such as “Request a site visit”.

Forms and feedback

Add a Form with labelled inputs and an explicit submit label. Use Email and Number field types where appropriate and make important fields required. A placeholder can show an example, while the visible label keeps the purpose clear after typing. When wiring a form to a workflow, confirm its field names match the workflow’s data keys.

Use a visible feedback block beside the form. In Logic, connect Form submission to the relevant action and use separate messages for success and error. A Set text node can display those messages. If the form is intended to store or deliver data, connect a suitable data or backend node and test the resulting record or response as well as the text. See the Blueprint recipes.

Start from an editable template

Choose from 12 editable projects. Open a Desktop screenshot or reveal its Phone preview before downloading. Save your current draft with Download .plot project, then use Import project to open a downloaded .plot file. In the imported draft, use Layers to inspect the sections, update the content and open Preview.

To add a single page inside your current project, use Pages and Add page. The built-in page options include Product landing page, Portfolio, Documentation and Contact. Add an appropriate URL slug, then replace demo names, images, links and any sample instructions.

Three layouts to rebuild

An architecture project lead

Open Quiet Forms and start with its Desktop Preview. The page introduces the work with a tall photograph beside a short headline. To build your own version, make a Section with a Columns block, place the heading and action in one child, and set the Image in the other. Try a minmax(0, 2fr) minmax(0, 3fr) grid and a 40px gap. Give the image a descriptive caption if the setting or material matters to the story. Set the grid to one track on Phone and check that the heading and contact path still come before the image.

A masthead that can hold a publication

In Margin Notes, the title and one sentence introduce the publication before readers reach the archive. Use a Heading for the masthead, a Text block for the introduction and a list of issues in reading order. Use size and a border to separate the masthead from the archive. Try clamp(48px, 10vw, 140px) for the main title, but test it using your actual publication name. Give the issue summaries a reading-width maximum and leave the wider section available for images and links.

A restaurant menu with aligned prices

Use Late Table to see how a menu can sit below a large typographic opening. Add a Table with headings for dish, ingredients and price, and use one row per dish. Keep the names and prices as text so visitors can select or read them with assistive tools. Check the longest dish name on the phone artboard. Shorten labels, move long descriptions below the table if needed, then verify that the price still sits beside the right dish.

See the settings in Studio

Open any screenshot at full size to read the field names and values. The Design and Preview controls show which device is selected.

Review the page before handoff

  • Open each page from its menu and follow the main action all the way through.
  • Compare Desktop, Tablet and Phone. Check headings, fixed widths, reading order and image crops with actual content.
  • Tab through the page. You should be able to locate your focus, operate navigation and reach all required inputs and actions.
  • Test a successful form request and a rejected one. Confirm that the visible messages and actual data changes agree.
  • Save a dated editable .plot checkpoint. For a delivered site, open the exported or published version to check its links and image URLs.
